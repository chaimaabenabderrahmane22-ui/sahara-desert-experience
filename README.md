# Sahara Desert Experience 🏜️✨

An immersive landing page showcasing the beauty, tourism, and rich cultural heritage of the Algerian Sahara desert.

## 🌟 Features
* **Hero Banner:** Stunning visual entry featuring golden dunes and sunset aesthetic.
* **Excursion & Tour Cards:** Highlighted desert activities (camel trekking, stargazing, quad biking).
* **Cultural Gallery:** Visual showcase of traditional architecture, music, and local hospitality.
* **Booking / Inquiry Form:** Contact section for custom travel bookings and guides.

## 🛠️ Built With
* **HTML5:** Clean and accessible markup.
* **CSS3:** Warm earth-tone color palettes, smooth hover animations, and responsive flex layouts.
